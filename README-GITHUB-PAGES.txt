GitHub Pages

1. Extract the ZIP.
2. Upload the CONTENTS of the extracted folder to the repository root.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.

The repository root must contain index.html and the myhome folder side by side.
The root index.html is the full homepage.
Do not upload myhome/index.html as the repository root index.html.

Notion Integration Secret must never be committed to GitHub.
